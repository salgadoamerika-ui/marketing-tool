---
name: Skip feedback intent
description: Retained skipped posts, gentle service-specific preferences, and one opt-in alternative.
---

Skip is distinct from Done and Planned. Keep the post in the record and share its status across Month and Week. Offer Undo skip; marking a skipped post done restores the normal completion path.

Each skipped post is preference feedback for its own content type, service, and business. A single skip gently lowers suggestion frequency; repeated skips lower it further, but never ban a type. This is explicit preference feedback, not a performance claim, so it does not require three measured posts.

Offer exactly one calm strategic alternative, not a list or a reschedule of the same unwanted task. Paid skips can offer an organic repost; a skipped testimonial can offer a lighter proof post. New alternatives remain opt-in and respect enabled content types, duplicates, and Campaign deadlines.

**Why:** The user wants skipping to teach the tool without punishment or nagging, and explicitly says one service's skips must not affect other services.

**How to apply:** Use retained skipped records for scoped preference feedback. Exclude skipped posts from published-performance evidence. Keep the existing weekly heartbeat and completion behavior; an offered alternative must never silently create or delete calendar posts.
